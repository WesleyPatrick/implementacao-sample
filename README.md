# Atividade Flutter - Layout e Cookbook

## a) Layout - `a_layout/`

Layout do tutorial https://docs.flutter.dev/ui/layout/tutorial com o tema da Antiga Estação Ferroviária de Rio do Sul - SC.

## b) Cookbook modificado - `b_cookbook_dismissible/`

Baseado no cookbook "Implement swipe to dismiss" (https://docs.flutter.dev/cookbook/gestures/dismissible), transformado em uma lista de compras.

## Como rodar

```bash
cd a_layout
flutter pub get
flutter run -d chrome
```

O mesmo vale para `b_cookbook_dismissible`.
